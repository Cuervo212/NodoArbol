# NodoArbol 🌳

A **Java** implementation focused on the study and management of non-linear data structures, specifically designed for creating, manipulating, and traversing **Binary Trees**.

## 🛠️ Tech Stack

* **Language:** Java 
* **Build Tool:** Apache Maven
* **Paradigm:** Object-Oriented Programming (OOP)
* **Core Concept:** Custom Binary Tree node structure and traversal algorithms (Pre-order, In-order, Post-order).
